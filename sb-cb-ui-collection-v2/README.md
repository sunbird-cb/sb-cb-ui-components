# SB-CB Collection V2

This repository contains the Sunbird CB CollectionV2 library.

## Project Structure

- `library/sunbird-cb/collectionV2` - CollectionV2 library

## Build

Run `npm run build` to build the project. The build artifacts will be stored in the `dist/` directory.

## Testing

Run `npm test` to execute the unit tests via [Karma](https://karma-runner.github.io).

## Development

This is an Angular workspace configured for library development.

## Installation

```bash
npm install
```

## Building the library

```bash
npm run build
```
